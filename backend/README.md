# Backend

S02 will generate the initial Java Spring Boot application in `app/`.

Planned foundation: Maven wrapper, Web, Validation, Data JPA, Spring Security, Actuator, MySQL and Flyway. Versions and exact commands will be recorded during S02.

Business rules live in [the shared rules document](../docs/business-rules.md). Later steps will extract web-api, ride-service and notification-service; these services do not exist yet.
